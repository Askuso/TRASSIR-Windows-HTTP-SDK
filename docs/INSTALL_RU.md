# Установка

## 1. Настройте TRASSIR

1. Откройте настройки WebServer/SDK TRASSIR.
2. Включите HTTP SDK.
3. Разрешите чтение настроек SDK.
4. Разрешите чтение дерева объектов SDK.
5. Запишите порт SDK и SDK-пароль.
6. Проверьте, что Windows-сервер доступен с Zabbix Server или назначенного Proxy.

SDK-пароль может отличаться от пароля учётной записи оператора.

## 2. Импортируйте шаблон

1. Откройте **Сбор данных → Шаблоны → Импорт**.
2. Выберите `templates/7.2/template_app_trassir_windows_http_sdk.xml` или XML из последнего Release.
3. Импортируйте все объекты шаблона.
4. Убедитесь, что в списке появился `Template App TRASSIR Windows HTTP SDK`.

## 3. Создайте узел

1. Создайте отдельный узел Zabbix для каждого Windows-сервера TRASSIR.
2. Добавьте интерфейс Agent с IP-адресом или DNS-именем сервера TRASSIR.
3. При необходимости выберите Zabbix Proxy.
4. Привяжите `Template App TRASSIR Windows HTTP SDK`.
5. Задайте обязательные макросы:

```text
{$TRASSIR.SCHEME}=https
{$TRASSIR.PORT}=8080
{$TRASSIR.SDK.PASSWORD}=ваш_sdk_пароль
```

Интерфейс Agent используется только как адрес назначения. Zabbix Agent на сервер TRASSIR не устанавливается.

## 4. Исключение дисков

Для дисков, которые не используются для записи архива:

```text
{$TRASSIR.DISK.EXCLUDE}=C,D,R
```

Элементы и графики продолжают работать; подавляются только проблемы дисковых триггеров.

## 5. Проверьте сбор данных

Сначала проверьте:

- `System: RAW - health and local channels`
- `Storage: RAW - archive disks`
- `System: RAW - aggregate polling errors`

Затем убедитесь, что правила обнаружения камер и дисков создают ресурсы.

Для немедленного запуска выполните RAW-элементы и оба правила LLD вручную.

## 6. Проверьте дашборд

Откройте дашборд узла/шаблона и убедитесь, что:

- системные статусы показывают `OK`;
- заполнено общее и доступное количество камер;
- CPU и архивные индикаторы получают значения;
- создаются графики камер и дисков;
- исключённые диски не создают проблемы после обновления LLD.

## Обновление

Импортируйте новый XML поверх существующего шаблона. Привязки узлов и переопределённые макросы сохраняются. После импорта выполните мастер-элементы и LLD, затем проверьте проблемы и дашборд.
