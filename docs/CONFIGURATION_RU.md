# Настройка

## Обязательные макросы узла

| Макрос | Пример | Назначение |
|---|---|---|
| `{$TRASSIR.SCHEME}` | `https` | Схема HTTP SDK. |
| `{$TRASSIR.PORT}` | `8080` | Порт HTTP SDK этого сервера. |
| `{$TRASSIR.SDK.PASSWORD}` | `********` | Пароль из настроек WebServer SDK TRASSIR. |

## Интервалы опроса

| Макрос | По умолчанию | Назначение |
|---|---:|---|
| `{$TRASSIR.POLL.INTERVAL}` | `2m` | Мастер-опрос health и дерева объектов. |
| `{$TRASSIR.CHANNEL.POLL.INTERVAL}` | `5m` | Опрос каждой камеры. |
| `{$TRASSIR.DISK.POLL.INTERVAL}` | `5m` | Опрос архивных дисков. |

Не используйте без необходимости слишком короткие интервалы. Дублирующий опрос может активировать защиту сессий TRASSIR.

## Пороговые макросы

| Макрос | По умолчанию | Назначение |
|---|---:|---|
| `{$TRASSIR.CPU.WARN}` | `85` | Порог загрузки CPU, %. |
| `{$TRASSIR.RECORD.DEBT.WARN}` | `5` | Порог задолженности записи камеры, секунд. |
| `{$TRASSIR.ARCHIVE.MIN.DAYS}` | `7` | Минимальная общая глубина основного архива. |
| `{$TRASSIR.CHANNEL.ARCHIVE.MIN.DAYS}` | `7` | Минимальная глубина архива камеры. |

## Исключение дисков

`{$TRASSIR.DISK.EXCLUDE}` принимает список ID через запятую:

```text
C
C,D
C,D,R
```

Пробелы и регистр игнорируются. Для исключённых дисков продолжают собираться данные и строиться графики; подавляются только проблемы триггеров.

После изменения макроса выполните LLD архивных дисков или дождитесь следующего цикла.

## Нормализация статусов

Отображаемые состояния подсистем используют:

```text
-1 = No data
 0 = Error
 1 = OK
```

TRASSIR Windows может возвращать обратную семантику поля сети. Значение сети нормализуется на preprocessing, поэтому все системные триггеры используют единую логику.

## Обнаружение камер

Обнаруживаются только локальные каналы текущего сервера TRASSIR. Удалённые каналы NetworkNode исключаются.

GUID канала используется как стабильный технический идентификатор. Имя камеры используется в видимых названиях и тегах.

Поведение потерянных ресурсов:

- Отключение через 1 час.
- Удаление через 30 дней.

## Статус камеры и зависимости

Доступность камеры берётся напрямую из:

```text
/settings/channels/{GUID}/flags/signal
```

Offline-триггер имеет важность `DISASTER`. Триггер видеосигнала зависит от Offline и не создаёт дублирующую проблему.

## Аппаратная запись

Не каждая камера возвращает флаг аппаратной записи:

```text
-1 = Not supported
 0 = Inactive
 1 = Active
```

`Not supported` является информационным значением и не создаёт проблему.

## Базовая линия архива

Рассчитываются:

- Текущая глубина основного архива.
- Полные дни архива.
- Скользящее среднее за 7 дней.
- Процент текущей глубины относительно среднего, максимум 100%.

Триггеры относительной глубины требуют нахождения ниже порога в течение 30 минут.
