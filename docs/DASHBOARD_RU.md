# Дашборд

Шаблон содержит готовый дашборд для одного Windows-сервера TRASSIR.

## Основные разделы

- Состояние сервера и подсистем.
- Количество доступных и общее количество камер.
- Радиальный индикатор доступности камер.
- Загрузка CPU.
- Текущая глубина основного архива.
- Полные дни архива.
- Средняя глубина архива за 7 дней.
- Глубина архива относительно базовой линии.
- Активные проблемы.
- Графики камер, архива и дисков.

## Интерпретация

### Доступность камер

Индикатор рассчитывается по количеству доступных и общему количеству локальных камер.

- 100% означает, что все обнаруженные локальные камеры онлайн.
- Меньшее значение означает, что одна или несколько камер недоступны.

### Базовая линия архива

Для архива используется обратная эксплуатационная логика: меньшее значение хуже.

```text
90–100%   Норма
80–89,99% Предупреждение
Ниже 80%  Критическое снижение
```

Процент сравнивает текущую глубину основного архива со скользящим средним за 7 дней. Оценивайте его вместе с полным количеством текущих дней и средним значением.

### Карточки статусов

Состояния подсистем используют нормализованные значения:

```text
0 = Error
1 = OK
```

`No data` означает, что необходимое значение SDK не получено.

## Где находится дашборд

Дашборд относится к шаблону и узлу. Он не создаётся как глобальная панель в разделе **Мониторинг → Панели**.

Откройте контролируемый узел и выберите его дашборд.

## Пустые виджеты

Виджет может оставаться пустым, если:

- первый мастер-опрос ещё не завершился;
- нужное поле отсутствует в SDK;
- вычисляемому элементу не хватает истории;
- обнаруженный ресурс помечен как потерянный;
- узел контролируется не тем Proxy, который ожидался.

Перед изменением дашборда проверьте RAW-элементы и последние данные.
