# FAQ

## Нужен ли Zabbix Agent?

Нет. Элементы типа Script отправляют HTTP SDK-запросы с Zabbix Server или Zabbix Proxy. Интерфейс Agent используется только как IP-адрес или DNS назначения.

## Почему значок ZBX серый?

Значок показывает доступность Zabbix Agent, а не HTTP SDK. Для проверки TRASSIR используйте дашборд и RAW-элементы.

## Почему отсутствуют удалённые камеры NetworkNode?

Шаблон специально обнаруживает только локальные каналы текущего сервера TRASSIR. Камеры подключённых удалённых серверов исключаются из локального LLD.

## Почему аппаратная запись показывает `Not supported`?

Не каждая камера или способ подключения возвращает `recording_hw`.

```text
-1 = Not supported
 0 = Inactive
 1 = Active
```

Это информационное значение и оно не создаёт проблему.

## Почему удалённая камера остаётся в Zabbix?

LLD не удаляет потерянные ресурсы сразу. По умолчанию они отключаются через 1 час и удаляются через 30 дней. Это защищает историю от временных SDK-сбоев.

## Как подавить проблемы для неархивных дисков?

Задайте макрос узла:

```text
{$TRASSIR.DISK.EXCLUDE}=C,D,R
```

После этого выполните LLD архивных дисков или дождитесь следующего цикла.

## Почему процент архива нестабилен после установки?

Индикатор использует скользящее среднее за 7 дней. Он становится показательным после накопления достаточной истории.

## Почему нет мониторинга RAM?

Использование памяти не было стабильно доступно в протестированных ответах TRASSIR Windows HTTP SDK. Для аппаратных регистраторов используется отдельный шаблон со своим набором системных метрик.

## Почему появляется `sessionbomb protection`?

Сервер получает слишком много одновременных или повторяющихся SDK-запросов. Удалите дублирующие шаблоны и исследовательские элементы либо увеличьте интервалы опроса.

## Где находится дашборд?

Это дашборд узла/шаблона. Открывайте его из контролируемого узла. В глобальном разделе **Мониторинг → Панели** он не создаётся.
